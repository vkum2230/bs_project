================================================================================
                    SMART RIDE 智能骑行码表 — 功能开发总规划
================================================================================
项目定位：基于树莓派5B + STM32 的带屏智能码表
数据链路：STM32(采集) → 串口 → 树莓派PyQt(显示/智能/存储) → 蓝牙/WiFi → App
当前状态：核心UI、语音、大模型、在线地图、通信层、数据持久化层、安全告警系统均已完成

【一】当前已实现功能清单
────────────────────────────────────────────────────────────────────────────────

1. [完成] PyQt5 主界面系统
   - 速度表、功率表（自定义 CircleGauge 控件）
   - 传感器数据卡片：踏频、坡度、温度、心率、后方来车距离
   - 运动数据卡片：骑行时长、骑行距离、平均速度
   - 顶部状态栏（WiFi状态、zt_flag 骑行状态、航向、时间、页面切换）
   - 消息/对话显示区（支持多行、流式输出、语音播报历史）
   - 数据/地图/历史/设置 四大页面

2. [完成] STM32 串口数据采集（JSON 协议）
   - 串口 /dev/ttyAMA2 读取
   - JSON 格式数据解析（core/protocol.py）
   - 数据实时刷新到 UI、DataContext、RideService、AlertService

3. [完成] 高德在线地图 + 实时导航
   - Web 地图嵌入（JS API）
   - 实时位置标记（蓝色定位点）
   - IMU 航偏角 yaw 方向指示（蓝色扇形箭头，0°正北，精确到1度）
   - 省份变化自动检测与语音播报
   - 拼音输入法键盘（点击输入框唤出、点击外部隐藏、候选词翻页）
   - 地点搜索 + 路线规划（绿色路线 + 方向箭头）
   - 导航模式（红色直线连接起点终点，保留规划路线）
   - 历史轨迹回放（加载 GPX/FIT 轨迹到地图）

4. [完成] 离线语音系统
   - Piper 本地 TTS 引擎封装
   - Edge-TTS 在线回退（混合播放器 HybridVoicePlayer）
   - 多种播放器降级策略（ReSpeaker/AOSS/PyAudio/pygame/pyttsx3）
   - 欢迎语音自动播报

5. [完成] 按钮语音交互
   - ReSpeaker 物理按钮触发（GPIO 17）
   - 按住录音、松开发送
   - LED 状态指示（呼吸灯/红/绿）

6. [完成] Ollama 本地大模型问答
   - 自动检测 Ollama 服务并启动
   - 自动选择可用模型（my-llama/llama3.2/qwen 优先级排序）
   - 支持极速模式、异步模式、流式输出
   - 超时 30s（极速）/ 60s（流式）

7. [完成] 数据上下文管理器 (DataContextManager)
   - 单例模式线程安全
   - 维护速度、功率、踏频、距离、时间、坡度、温度、心率、后方距离、位置、航向
   - 自动生成自然语言描述（供大模型作为 system prompt 上下文）

8. [完成] 位置服务
   - 离线省份判断（基于坐标反查）
   - 语音播报"进入XX省"

9. [完成] 串口调试器
   - 串口日志重定向到 /dev/ttyAMA10，方便外接调试

10. [完成] 通信层
    - 经典蓝牙 RFCOMM Server（drivers/ble_server.py）
    - WiFi WebSocket Server（端口 8765）
    - 通信调度器 CommService（BLE + WiFi 统一调度）
    - MQTT 调试桥接器（broker.emqx.io）
    - 断连缓存队列（persistence/buffer_queue.py）

11. [完成] 骑行会话管理（RideService）
    - 开始/暂停/恢复/结束骑行按钮逻辑
    - 骑行时间累计（排除暂停时间）
    - 骑行距离、平均速度计算
    - 联动 FIT 文件打开/关闭

12. [完成] 本地骑行记录存储（FIT/GPX）
    - 每次骑行自动创建 FIT/GPX 文件
    - 实时写入轨迹点（时间戳、坐标、速度、心率、功率...）
    - 历史记录页面支持列表查看和轨迹回放

13. [完成] 智能安全告警系统（AlertService）
    - 后方来车告警：rear_dist < 阈值 时语音+LED 红灯闪烁告警
    - 心率异常告警：心率超过用户设置上限/下限时语音告警
    - 疲劳告警：连续骑行超过 4 小时提醒休息
    - 跌倒检测：zt_flag == 0 时立即触发 critical 级告警（语音+LED+消息框），60秒冷却
    - 统一冷却去重机制，防止重复鬼畜

14. [完成] 用户配置管理 + 设置页面
    - 心率上限/下限、体重、年龄、后方来车阈值
    - 告警开关（后方来车/心率/疲劳/跌倒）
    - 配置持久化到 ~/smartride/config.json

【二】STM32 → 树莓派 当前串口数据协议
────────────────────────────────────────────────────────────────────────────────

```json
{
  "speed": 25.4,
  "cadence": 90,
  "power": 220,
  "distance": 15.25,
  "ride_time": 3600,
  "slope": 3.5,
  "zt_flag": 5,
  "yaw": 60,
  "temperature": 26.5,
  "heart_rate": 145,
  "rear_dist": 12.5,
  "err_code": 0,
  "location": {
    "lat": 31.230416,
    "lon": 121.473701
  }
}
```

字段说明：
| 字段         | 类型  | 说明                                                    |
|--------------|-------|---------------------------------------------------------|
| speed        | float | 速度 km/h                                               |
| cadence      | float | 踏频 rpm                                                |
| power        | float | 功率 W                                                  |
| distance     | float | 骑行距离 km                                             |
| ride_time    | int   | 骑行时间秒                                              |
| slope        | float | 坡度 %                                                  |
| zt_flag      | int   | 骑行状态：0=跌倒 1=右转弯 2=左转弯 3=上坡 4=下坡 5=正常 |
| yaw          | float | IMU 航偏角，0°指北，顺时针增加                          |
| temperature  | float | 温度 °C                                                 |
| heart_rate   | float | 心率 bpm                                                |
| rear_dist    | float | 后方来车距离 m                                          |
| err_code     | int   | 错误码（0=正常）                                        |
| location     | object| GPS 坐标 {lat, lon}                                     |

【六】给 Claude Code 的开发提示
────────────────────────────────────────────────────────────────────────────────

1. 高德地图是在线的：当前 map_widget.py 依赖网络，户外无网会白屏。任何地图修改要考虑"离线可用性"。
2. 树莓派性能有限：Ollama 已通过 num_ctx=512、num_thread=4 优化。新增 heavy 计算要评估 CPU 占用。
3. DataContext 是中心数据源：所有需要向 LLM 提供上下文或向 UI 刷新的功能，都应通过 data_context.py 读写。
4. 语音模块已高度封装：drivers/audio/piper_voice.py 的 HybridVoicePlayer 支持离线/在线自动切换，优先复用。
5. BLE Server 在 Linux 上的坑：bleak 做 Server 资料比 Client 少，可能需要直接调用 bluez D-Bus API。
