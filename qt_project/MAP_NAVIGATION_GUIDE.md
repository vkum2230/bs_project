# 地图导航功能说明

## 一、触摸手势操作

### 1. 双指缩放（放大/缩小）
- **操作**：用两根手指在地图上同时向外或向内滑动
- **效果**：放大或缩小地图比例尺
- **适用场景**：查看不同范围的地图区域
  - 放大：看清道路细节、路口
  - 缩小：查看整体路线规划

### 2. 地图旋转
- **操作**：用两根手指旋转（一个顺时针/逆时针旋转）
- **效果**：旋转地图方向
- **适用场景**：调整地图朝向与骑行方向一致

### 3. 单指拖动
- **操作**：单指按住地图拖动
- **效果**：平移地图视角
- **适用场景**：查看当前位置周边区域

## 二、导航按钮说明

### 导航面板按钮（从左到右）

```
⌨️  🧭导航  ⏹️  🗑️
```

| 按钮 | 图标 | 名称 | 功能说明 |
|------|------|------|----------|
| 第1个 | ⌨️ | 键盘按钮 | 显示/隐藏虚拟键盘，用于输入目的地 |
| 第2个 | 🧭 | 导航按钮 | **开始导航** - 规划从当前位置到目的地的路线 |
| 第3个 | ⏹️ | 停止按钮 | **停止导航** - 结束当前导航，清除路线 |
| 第4个 | 🗑️ | 清除按钮 | **清除所有** - 清除搜索历史、轨迹和标记 |

### 详细功能说明

#### 1. ⌨️ 键盘按钮
- **点击效果**：显示/隐藏右侧虚拟键盘
- **用途**：输入目的地名称（拼音输入）
- **使用场景**：搜索想去的地方

#### 2. 🧭 导航按钮（核心功能）
- **点击效果**：
  1. 规划从当前GPS位置到目的地的最优路线
  2. 在地图上显示蓝色导航路线
  3. 显示预计距离和时间
  4. 开始语音导航播报
- **使用前提**：需要先有目的地（通过搜索设置）
- **骑行推荐**：会自动选择适合骑行的路线

#### 3. ⏹️ 停止按钮
- **点击效果**：
  1. 停止当前导航
  2. 清除地图上的蓝色路线
  3. 停止语音导航播报
  4. 保留当前位置和轨迹
- **使用场景**：到达目的或需要中断导航时使用

#### 4. 🗑️ 清除按钮
- **点击效果**：
  1. 清除所有搜索历史
  2. 清除骑行轨迹（蓝色线条）
  3. 清除起点/终点标记
  4. 重置地图状态
- **使用场景**：重新开始新的骑行记录时使用

## 三、地图控件说明

### 右下角控件

```
[旋转按钮]
[缩放滑块]
[方向按钮]
```

| 控件 | 功能 |
|------|------|
| 旋转按钮 | 点击恢复地图正北朝上 |
| 缩放滑块 | 点击 +/- 放大/缩小 |
| 方向按钮 | 恢复默认视角 |

### 左下角比例尺
- 显示当前地图比例
- 帮助判断实际距离

## 四、使用流程示例

### 场景1：导航去某地
```
1. 点击 ⌨️ 打开键盘
2. 输入目的地名称（如"天安门"）
3. 点击候选词选择目的地
4. 点击 🧭 导航 开始导航
5. 跟随蓝色路线骑行
6. 到达后点击 ⏹️ 停止导航
```

### 场景2：记录骑行轨迹
```
1. 确认GPS定位成功（显示📍）
2. 开始骑行，系统自动记录轨迹（蓝色线条）
3. 可随时双指缩放查看不同范围
4. 骑行结束点击 🗑️ 清除轨迹（如需保存请截图）
```

### 场景3：查看周边
```
1. 单指拖动地图查看周边
2. 双指缩放调整视野范围
3. 双指旋转调整地图方向
4. 点击右下角方向按钮恢复正北
```

## 五、注意事项

1. **GPS信号**：导航需要良好的GPS信号，室内可能无法定位
2. **网络连接**：在线地图需要网络，离线地图需提前下载
3. **电量消耗**：持续GPS定位会比较耗电，建议带充电宝
4. **安全第一**：骑行时请不要操作屏幕，安全停车后再操作
