# 地图触摸手势修复说明

## 问题诊断

高德地图 2.0 在 Qt WebEngine 中的触摸事件可能存在兼容性问题：
1. 双指缩放可能不响应
2. 双指旋转在 2D 模式下可能不支持

## 解决方案

### 方案1：触摸手势（自动）
代码已配置支持触摸手势：
```javascript
map = new AMap.Map('container', {
    dragEnable: true,      // 单指拖拽
    zoomEnable: true,      // 双指缩放
    rotateEnable: true,    // 双指旋转
    pitchEnable: false,    // 2D地图
    doubleClickZoom: true, // 双击缩放
    scrollWheel: true      // 滚轮缩放
});
```

**如果触摸手势正常工作：**
- 双指向外滑动 = 放大
- 双指向内滑动 = 缩小
- 双指旋转 = 旋转地图
- 单指拖动 = 平移地图

### 方案2：手动控制按钮（备选）
如果触摸手势不工作，请使用**右上角的手动控制按钮**：

```
[ + ]  放大
[ − ]  缩小
[ ← ]  向左旋转
[ → ]  向右旋转
[ ↑ ]  恢复正北
```

## 已添加的修改

### 1. main.py
- 启用高 DPI 支持
- 启用触摸事件合成

### 2. map_widget.py
- 添加触摸事件监听（调试用）
- 添加手动控制按钮（+/-/←/→/↑）
- 添加对应的 JavaScript 控制函数
- 加载 Scale, ToolBar, ControlBar 插件

## 测试方法

1. 运行程序：
```bash
cd qt_project
python3 main.py
```

2. 测试触摸手势：
   - 尝试双指缩放
   - 尝试双指旋转
   - 观察控制台是否有 touchstart/touchmove 日志

3. 如果触摸不工作，使用右上角按钮：
   - 点击 `+` 放大
   - 点击 `−` 缩小
   - 点击 `←` 向左旋转
   - 点击 `→` 向右旋转
   - 点击 `↑` 恢复正北

## 已知限制

1. **高德地图 2.0 的旋转功能**：在 2D 模式下旋转功能有限，可能需要切换到 3D 模式才能获得更好的旋转体验

2. **Qt WebEngine 触摸事件**：在某些系统上，Qt WebEngine 可能无法正确传递多点触控事件到 JavaScript

## 建议

如果触摸手势对您很重要，建议：
1. 使用手动控制按钮（已提供）
2. 或者考虑使用触摸屏的浏览器直接访问地图（绕过 Qt WebEngine）
3. 或者考虑降级到高德地图 1.4 版本（可能有更好的触摸支持）

## 按钮功能总结

### 导航按钮（左下角）
```
⌨️  键盘      - 显示/隐藏虚拟键盘
🧭  导航      - 开始导航
⏹️  停止      - 停止导航
🗑️  清除      - 清除所有标记
```

### 地图控制按钮（右上角）
```
+   放大      - 增加缩放级别
−   缩小      - 减小缩放级别
←   左旋      - 向左旋转15度
→   右旋      - 向右旋转15度
↑   正北      - 恢复正北朝向
```
