# 地图功能更新 - 输入提示与地理逆编码

## 新增功能

### 1. 输入提示优化

**功能描述：**
- 在搜索框输入时，自动显示匹配的地点候选列表
- 候选列表显示地点名称和详细地址（区/街道）
- 点击候选词自动在地图上标注该位置

**代码实现：**
```javascript
autoComplete = new AMap.AutoComplete({
    input: 'searchInput',
    city: '全国',
    citylimit: false,
    output: 'suggestionsList'
});
```

**使用方式：**
1. 点击 ⌨️ 键盘按钮打开虚拟键盘
2. 输入地点名称（如"天安门"、"故宫博物院"）
3. 从下拉列表中选择目标地点
4. 地图自动跳转到该位置并添加蓝色标记

### 2. 地理逆编码（点击地图获取地址）

**功能描述：**
- 点击地图任意位置，自动获取该位置的地址信息
- 使用高德地图 Geocoder 插件进行逆地理编码
- 获取省、市、区、街道等详细地址信息
- 在地图上显示临时标记（5秒后自动消失）
- 地址自动填充到搜索框

**代码实现：**
```javascript
var geocoder = new AMap.Geocoder({
    radius: 1000,
    extensions: 'all'
});

map.on('click', function(e) {
    geocoder.getAddress(e.lnglat, function(status, result) {
        // 处理地址信息并显示
    });
});
```

**使用方式：**
1. 直接在地图上点击任意位置
2. 左下角位置信息区域显示获取到的地址
3. 地图上显示红色临时标记
4. 搜索框自动填充地址名称
5. 可以基于此位置开始导航

### 3. 位置标记优化

**目的地标记（蓝色）：**
- 从候选列表选择后显示
- 带标签显示地点名称
- 使用 drop 动画效果

**临时标记（点击地图）：**
- 点击地图任意位置显示
- 5秒后自动消失
- 显示地址标签

## 使用流程

### 场景1：搜索已知地点
```
1. 点击 ⌨️ 打开键盘
2. 输入"故宫"
3. 从列表选择"故宫博物院"
4. 地图自动跳转并标记
5. 点击 🧭 开始导航
```

### 场景2：选择地图上的点
```
1. 直接在地图上点击目标位置
2. 等待地址解析（约1秒）
3. 查看左下角显示的地址
4. 点击 🧭 开始导航
```

### 场景3：精确位置导航
```
1. 搜索大致位置（如"北京大学"）
2. 在地图上微调点击精确位置
3. 确认地址后点击 🧭 导航
```

## API 依赖

加载的插件：
- `AMap.AutoComplete` - 输入提示
- `AMap.PlaceSearch` - 地点搜索
- `AMap.Geocoder` - 地理/逆地理编码
- `AMap.Driving` - 路线规划
- `AMap.Scale` - 比例尺

## 注意事项

1. **网络依赖**：输入提示和逆编码需要网络连接
2. **API Key**：确保使用有效的 Web 端高德地图 Key
3. **响应时间**：逆编码可能有1-2秒延迟
4. **精度**：点击地图的精度取决于地图缩放级别
