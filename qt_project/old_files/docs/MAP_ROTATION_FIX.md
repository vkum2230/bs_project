# 地图旋转功能说明

## 问题原因

**高德地图 2.0 在 2D 模式下不支持旋转功能。**

这是高德地图 API 的限制，不是代码 bug。

## 当前状态

| 功能 | 状态 | 说明 |
|------|------|------|
| 放大/缩小按钮 | ✅ 正常 | 使用 `map.setZoom()` |
| 双指缩放 | ⚠️ 可能有效 | 取决于触摸屏驱动 |
| 旋转按钮 | ❌ 无效 | 2D 模式不支持旋转 |
| 双指旋转 | ❌ 无效 | 2D 模式不支持旋转 |

## 技术细节

### 高德地图 API 限制

```javascript
// 高德地图 2.0
map = new AMap.Map('container', {
    viewMode: '2D',  // 2D 模式下旋转 API 无效
    rotateEnable: true  // 这个参数在 2D 模式下被忽略
});

// 尝试旋转
map.setRotation(45);  // 在 2D 模式下无效果
map.setStatus({rotation: 45});  // 在 2D 模式下无效果
```

### 为什么保持 2D 模式？

虽然 3D 模式支持旋转，但：
1. **骑行导航体验差** - 3D 模式下道路显示不够清晰
2. **性能消耗大** - 3D 渲染需要更多资源
3. **导航算法** - 骑行导航通常使用 2D 视图

## 解决方案

### 方案 1：保持现状（推荐）

继续使用 2D 模式，放弃旋转功能。
- ✅ 骑行导航体验最佳
- ✅ 地图清晰度高
- ❌ 无法旋转地图

### 方案 2：切换到 3D 模式

如果需要旋转功能，可以修改代码：

```javascript
map = new AMap.Map('container', {
    viewMode: '3D',  // 改为 3D 模式
    pitch: 0,        // 俯视角度
    rotation: 0      // 初始旋转角度
});
```

**缺点：**
- 3D 模式下道路不如 2D 清晰
- 可能影响骑行导航体验
- 部分 tile 加载可能有问题

### 方案 3：使用 CSS 旋转（实验性）

代码中已经添加了 CSS 旋转作为备选：

```javascript
// 如果 API 旋转失败，使用 CSS 旋转整个容器
container.style.transform = 'rotate(45deg)';
```

**缺点：**
- 标记和文字也会旋转，影响阅读
- 不是真正的地图旋转
- 交互体验差

## 建议

对于骑行导航场景，**建议保持 2D 模式**，理由：

1. **地图朝北** 是导航的标准做法
2. **道路清晰** 比方向更重要
3. **减少干扰** 不需要频繁旋转地图

如果需要调整方向，可以通过 **平移地图** 来查看不同区域。

## 可用功能

当前可用的地图操作：
- ✅ 双指/按钮放大缩小
- ✅ 单指拖动平移
- ✅ 双击放大
- ✅ 滚轮缩放
- ❌ 旋转（API 限制）

## 按钮功能

右上角按钮：
```
[+]  放大地图
[-]  缩小地图
[←]  尝试向左旋转（可能无效）
[→]  尝试向右旋转（可能无效）
[↑]  恢复正北（重置旋转）
```

左下角按钮：
```
⌨️  键盘 - 输入目的地
🧭  导航 - 开始导航
⏹️  停止 - 停止导航
🗑️  清除 - 清除轨迹
```
