一、
第一个界面：
前端界面：连接手机方式，wifi（二维码扫码），蓝牙（按钮：按下其它设备可连接到本蓝牙，而不是像现在这样一直打开蓝牙等待别人连接）
wifi：app端扫码往mqtt的appHeart_1主题发消息，消息体为{isConnect:"OK"}，我接收到消息mqtt往deviceHeart_1主题发送{isConnect:"OK"}，这时候表示已经连接到手机，跳转到数据界面
蓝牙：按钮的形式打开蓝牙，其它设备可以连接到树莓派进行串口通信，树莓派的物理地址为：2C:CF:67:F2:ED:B2
其中任意一个连接成功即可跳转到下一个界面
之后持续每5s往deviceHeart_1主图发送一个消息为心跳，消息体为{isConnect:"continue"}
用户也可以选择跳过连接，直接进入数据界面，在最上方的状态栏有一个标识符，如果未连接app，则显示连接字符，如果连接到了app，则是手机图标，长按图标可以主动断开与app端的连接，消息体为{isConnect:"OK"}点击连接则可以跳到第一界面再次选择连接到手机，这个也作为一个全局标志位，名为connect，wifi连接为1（只有mqtt发数，websocket暂时删除），蓝牙连接为2，否则为0
这个标志位也决定了后续会往哪个通道发数据，如果是0就不发

mqtt：
实时数据（通过deviceData_1主题发送）：
{
  "type": "realtime",                  // 消息类型：实时数据
  "timestamp": 时:分:秒,               // 时间戳：时:分:秒
  "data": {                            // 数据体
    "speed": 速度,                     // 速度：km/h
    "cadence": 踏频,                   // 踏频：rpm
    "power": 功率,                     // 功率：W
    "heart_rate": 心率,                // 心率：bpm
    "slope": 坡度,                     // 坡度：%
    "temperature": 温度,               // 温度：℃
    "rear_dist": 后方来车距离,         // 后方来车距离：m
    "gps": {                           // GPS 坐标
      "lat": 经度,                     // 纬度
      "lon": 纬度                      // 经度
    }
  }
}

非实时数据（通过delayData_1主题发送）
报警：

  "type": "event",                     // 消息类型：事件
  "timestamp": 时:分:秒,               // 时间戳：时:分:秒
