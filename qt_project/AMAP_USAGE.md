# 高德地图导航使用指南

## 🗺️ 功能概述

已集成高德地图 API，支持以下功能：

1. **在线地图显示** - 高德矢量地图，深色主题
2. **地点搜索** - 输入地名自动补全
3. **骑行导航** - 路径规划 + 实时导航指令
4. **GPS 定位** - 实时显示位置 + 轨迹记录
5. **虚拟键盘** - 触屏输入支持

---

## 🚀 快速开始

### 1. 启动程序
```bash
python3 main.py
```

### 2. 切换到地图页面
点击顶部导航栏的 **"地图"** 按钮

### 3. 搜索目的地
1. 点击搜索框，弹出虚拟键盘
2. 输入目的地名称（如"深圳北站"）
3. 输入时会自动显示匹配地点列表
4. 点击列表中的地点选择

### 4. 开始导航
1. 点击 **"🧭 导航"** 按钮
2. 地图显示规划路线
3. 底部显示导航信息（距离、时间、转向指令）
4. 跟随 GPS 移动，自动更新导航指令

### 5. 停止导航
点击 **"⏹️"** 按钮停止导航

## 📍 GPS 数据格式

串口发送的 GPS 数据格式：
```json
{
  "speed": 25.5,
  "power": 180,
  "location": {
    "lat": 22.543099,
    "lon": 114.057868
  }
```

## ⚠️ 注意事项

### 1. 网络要求
- 高德地图需要联网使用
- 首次加载需要下载地图资源（约 1-2MB）
- 导航过程中持续消耗流量（约 100KB-1MB/小时）

### 2. 流量优化建议
- 如果网络不稳定，导航可能中断
- 建议在信号好的区域使用
- 可以预先用手机热点测试

### 3. Key 安全
- 当前 Key 是 Web 端 Key，有调用限制
- 如需商用或大量调用，请申请企业 Key
- Key 泄露可能导致被滥用

## 🔧 常见问题

### Q: 地图加载失败？
**A:** 检查网络连接：
```bash
ping webapi.amap.com
```

### Q: 搜索没有结果？
**A:** 
1. 检查网络是否正常
2. 确认输入了至少 2 个字符才会触发搜索
3. 尝试输入具体地点（如"深圳市深圳北站"）

### Q: 导航路线不正确？
**A:**
1. 高德导航默认是驾车模式，已改为最短距离策略
2. 如需纯骑行路线，需升级为企业版 Key
3. 当前版本适合城市和郊区骑行

### Q: 如何切换地图样式？
**A:** 在 `map_widget.py` 中修改：
```javascript
// 可选样式：
// normal - 标准
// dark - 深色（当前）
// light - 浅色
// macaron - 马卡龙
mapStyle: 'amap://styles/dark'
```
